# Local integration icons

Integration symbols are bundled locally from Simple Icons 16.0.0, except OpenAI, Salesforce, and Slack, which use version 13.0.0:
https://github.com/simple-icons/simple-icons/tree/16.0.0/icons

Source files are CC0-1.0; see SIMPLE-ICONS-LICENSE.md. Brand names and trademarks remain owned by their respective companies. The Meta SVG uses Meta blue (#0866FF); masks apply provider colors to the other icons without altering their paths.

The Webhooks symbol uses the existing Lucide React dependency and is rendered inline. No external image request or additional icon runtime is required for integration logos.

The Meta symbol is paired in HTML with the user-requested "WhatsApp Cloud API" (no partner claim) wording; it is not a downloaded certification badge or a newly verified accreditation. Meta brand reference: https://www.meta.com/brand/resources/meta/company-brand/
